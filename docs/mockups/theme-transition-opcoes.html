Transição sol / lua — 3 versões

Escolha uma versão e use o botão de tema no rodapé do menu (palco abaixo) ou os atalhos em cada cartão. A troca claro ↔ escuro do palco acontece no meio da animação, como no app.

Versão 1

Atual (app hoje)

Rápida (~1,1s), halo bem amarelo, ícone médio (~60px).

  • Boa para não atrasar o uso
  • Pode parecer “flash” amarelo
Versão 2

Cinemático

~2s, ícone maior (~88px), claro neutro (pouco amarelo).

  • Gradiente pérola / cinza claro
  • Equilíbrio velocidade × presença
Versão 3

Monumental

~2,6s, ícone grande (~120px) sobe com a onda; noite índigo.

  • Mais teatral
  • Sol/lua “ocupam” a tela
