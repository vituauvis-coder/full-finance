# Viagens — roteiro de aceite manual

1. **Casa:** abrir Viagens → mapa, trilho, Nova viagem cria e abre ficha.  
2. **Trilho:** ordem em curso → planejadas → realizadas; barra de teto visível.  
3. **Ficha:** título, datas, checklist, autosave (~1,2s) sem barra sobreposta.  
4. **Orçamento:** meta, cofrinho, categorias, lançamentos refletem gastos.  
5. **Destinos:** busca geocode, chips, mini-mapa, sincronizar roteiro.  
6. **Voos:** trechos, simulações, KPIs menor custo.  
7. **Hospedagens:** stays/legs com valores na engine.  
8. **Simulador:** overlay, novo cenário, snapshot/vencedor.  
9. **API:** `npm test` inclui `trips-engine.test.js`.
